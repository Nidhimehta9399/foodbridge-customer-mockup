Reproduced as-is, not "fixed"

No mobile card view, and half the table is unreachable on a phone. Unlike the Products module, the Customers table renders identically at every width. Worse, windmill's <Table> is w-full whitespace-nowrap inside an overflow-hidden container — so below ~900px the live app clips Catalog and Actions: no scroll, no wrap, no cards. Carried as an open question.

Tags are filter-only. Four tagged customers produce two chips with counts, but no row displays its own tag anywhere in the table.

The Address column is mostly dashes. Address is derived from [adress1, state.name, postnr] and collapses to - when every part is empty — which is the majority case in the As-is capture.

The sidebar is tenant data. Names, order, grouping and even the lucide icon names come from globalSetting.storefrontMenus. Two captures of this same tenant already differ — the menu here follows the later one.

Deliberate deviations

All B2B feature flags are on in seed.inline.js → appProp so every flow is reachable. The As-is capture came from a tenant with bulkImportEnabled: false, which is why Import / Export / Sample were not visible there. Flip the flags to reproduce any given tenant's exact surface.

Selected rows are green, and selection is scoped to its page — changing page, search or tag filter clears it. The live table marks nothing and can retain ids from a page you have left.

The mobile table scrolls rather than clipping, purely so this prototype stays reviewable on a phone. Everything else about the mobile table is as-is.

Not built this iteration

Catalog-to-Customer Mapping and Credit Wallet Mapping tabs (off in the captured tenant, and the credit tab is hard-disabled in the source), the Google Sheet export/sync panel, and the Customer Locations / Customer Order routes. Sidebar entries outside Customer Management raise a prototype notice.
Data from seed-data/seed.json, mirrored verbatim in seed.inline.js because file:// blocks fetching local JSON. Edits persist in localStorage for the session — run FB.reset() in the console to restore the seed.
Wiring hub and full transition map: discovery/index.html. Boot check: screens/customers/_smoke/.
